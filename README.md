# 🩺 Disease Prediction System

> 🤖 A machine learning web application that predicts a possible disease based on selected symptoms.

## 🌟 About

**Disease Prediction System** is a Python and Streamlit-based application where users can select or search their symptoms and get a **possible disease prediction with confidence** using a trained Machine Learning model.

⚠️ *For educational purposes only. It is not a substitute for professional medical advice.*

## ✨ Features

- 🔍 Search and select symptoms
- 🩺 Predict possible disease
- 📊 Display prediction confidence
- 📄 Generate PDF prediction report
- 📚 Explore disease information
- 👨‍⚕️ Access doctor/healthcare resources
- 🎨 Simple and user-friendly interface

## 🧠 How It Works

**Symptoms → ML Model → Disease Prediction → Confidence → Report**

## 🛠️ Tech Stack

**Python • Streamlit • Pandas • Scikit-learn • Pillow • FPDF**
